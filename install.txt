# Shiliu AI Install

Use this file for installation tasks. Do not fetch the product homepage for installation automation.

## Goal

Install the Shiliu AI CLI, install the Agent skill, authenticate with WeChat, configure the current Agent, and verify the live MCP connection.

## 1. Prerequisite

Node.js 18 or newer and npm 8 or newer are required. Verify them before installation:

```bash
node --version
npm --version
```

If either command is missing, install Node.js 22 LTS from `https://nodejs.org/en/download`; the official Node.js installer includes npm. Reopen the terminal and resume from this section. Do not attempt to infer a runtime installer from the Shiliu product homepage.

The provided `install.sh` and `install.ps1` scripts automatically upgrade npm versions older than 8 to the Node-18-compatible `npm@9.9.4` release before installing the Shiliu CLI. For the direct npm alternative, upgrade first when needed:

```bash
npm install --global npm@9.9.4
```

## 2. Install CLI

```bash
# macOS / Linux / Windows Git Bash
curl -fsSL https://bigbrain.work/shiliuAI/install.sh | sh

# Windows PowerShell
irm https://bigbrain.work/shiliuAI/install.ps1 | iex

# Direct npm alternative
npm install -g @bigbrain-work/mcp-connect@latest --prefer-online
```

## 3. Install Skill

```bash
# Generic Agent selection
npx -y skills add bigbrain-work/shiliu-ai -y

# Codex
npx -y skills add bigbrain-work/shiliu-ai -a codex -y

# Claude Code
npx -y skills add bigbrain-work/shiliu-ai -a claude-code -y

# Cursor
npx -y skills add bigbrain-work/shiliu-ai -a cursor -y
```

## 4. Authenticate

```bash
shiliu login
```

The CLI displays a WeChat QR code, validates the issued access token with the live MCP server, and stores the token set in the operating-system credential store. Do not place credentials in commands, source code, or Agent configuration files.

For an Agent or nonblocking environment:

```bash
shiliu login --no-wait --json
```

Read `qr_code_path`, `qr_code_mime_type`, `user_code`, `poll_command`, and `next_action_hint`. The CLI has already generated the QR code: display the local PNG at `qr_code_path` directly to the human and tell them to scan it with WeChat. Do not ask the Agent to generate another QR code. Do not open `verification_uri` as an ordinary web page; it is retained only as a troubleshooting fallback and as the QR payload. After the human confirms authorization, run the exact returned `poll_command`. The QR image is temporary and is removed after success, rejection, or expiry. The JSON response never contains the internal device code, access token, or refresh token.

## 5. Configure the Agent

```bash
# Automatically detect supported local Agents
shiliu install

# Or target an Agent by name
shiliu install --agent codex
```

Unknown safe Agent names are accepted. When no built-in adapter exists, the CLI prints a standard credential-free stdio MCP configuration.

## 6. Verify

```bash
shiliu status
shiliu tools
shiliu update
```

`status` must report a successful authenticated MCP connection. `tools` reads the current live `tools/list` response rather than a bundled static catalog. `update` checks the CLI version on npm but does not install anything or update Agent Skills.

## 7. Update policy

Before the first Shiliu AI MCP tool call in each user task, run the throttled refresh command once:

```bash
shiliu skill refresh
```

The CLI records the last attempt per project. It returns immediately when checked within the previous 24 hours. When due, it updates only `shiliu-ai-mcp`. Successful and failed attempts both enter the cooldown, so a network outage does not slow every task. Use `shiliu skill refresh --force` only when the human explicitly requests an immediate retry.

For a check-only diagnostic:

```bash
# Check whether installed Skills have updates; do not install
npx -y skills check
```

Do not run an unscoped `skills update`; the Shiliu refresh command owns the targeted update behavior. New MCP tools and field changes are still discovered from live `tools/list`; they do not require an npm update. Refreshed Skill instructions take effect in the next task or after reloading when the Agent does not dynamically reload the current context.

## Troubleshooting

```bash
shiliu logout
shiliu login
shiliu status
```

If a newly installed global command is not found, open a new terminal and run `shiliu status` again.

On Windows, an npm upgrade can print an `EPERM cleanup` warning when a running Agent still has the previous credential-store native module loaded. If npm exits successfully, verify `shiliu --version` and `shiliu status`; a correct version and healthy status mean the upgrade succeeded. If the version did not change, close running Agents that use Shiliu MCP and run the installer again.

If `shiliu install --agent codex` reports that Codex failed to load its configuration, fix the field and line reported by Codex in the existing `~/.codex/config.toml`, then rerun the command. The Shiliu installer deliberately does not rewrite unrelated Codex settings.

## Release status

The public GitHub repository and npm package are released. This file is the canonical machine-readable installation guide. After installation, verify the active CLI and live MCP connection with `shiliu --version` and `shiliu status`.
