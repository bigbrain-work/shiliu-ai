# CLI 1.3.17 发布说明

按已复核的连接生命周期设计实施。业务 isError 原样返回，JSON-RPC 业务异常不再拆掉健康连接或清空全部工具；临时凭据/认证故障保留最后成功目录，调用返回明确状态。明确本地无凭据/退出登录仍只展示基础工具。换令牌先建立新会话并发现全部目录，再原子切换；旧会话只排空已有请求后关闭，新连接失败保留仍健康的旧连接。

callTool 无论业务错误、HTTP401、超时、取消还是断连，均不自动重放。HTTP401只为后续请求重读凭据并建立连接；当前请求报告结果未知，不能据此声称没有执行或扣费。只有明确幂等 list* 等发现操作可在同一截止时间内恢复一次，重连前后目录完整分页读取，旧代次通知不能覆盖新目录。

请求默认空闲120秒、总时长15分钟。SDK options 按真实签名传递，callTool 使用第三参数。进度重置空闲期限，独立总计时器保证硬上限；只有上游提供 progressToken 才转发，并映射回该调用者的令牌。取消按请求转发，不能关闭其他请求。shiliu call 使用相同行为，读取全部目录页，Ctrl+C取消当前等待，清理监听器，stdout保持原有单份JSON。

工具变更通知触发完整分页目录重读；重复游标、页数上限、分页失败保留旧目录并报告，后台有界退避重试。关闭覆盖stdin end/close、传输关闭和信号，停止轮询、取消等待、关闭全部代次，避免因远端不退出永久等待。关闭和取消不证明远端业务已回滚。

验证包含实际SDK与本地HTTP/内存MCP：令牌换代排空、旧通知隔离、两并发请求进度/取消隔离、空闲/硬总期限、RPC和HTTP401后的精确执行次数、分页工具与不完整目录、CLI取消、迟到连接关闭。另实际运行65秒合成工具一次，验证默认不会在60秒误失败；Windows Node和cmd包装在途调用后关闭stdin均正常退出，不重放。没有调用生产付费工具。完整测试、公开包和真实客户端结果见下文，合成测试与真实客户端验收分别记录。

依赖及官网指南最低版本仍为1.3.12。真实macOS Keychain/Linux Secret Service故障未验收；未对所有第三方客户端运行环境作保证。设计PR #30已获用户复核，产品PR #32独立合入及发布。
